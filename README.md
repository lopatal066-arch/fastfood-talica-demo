# Fast Food Талица — демо витрины

Демо-страницы для местной точки фастфуда (г. Талица): показывают, как может выглядеть
онлайн-меню и заказ без переписки в сообщениях.

## Что внутри

- `/` — слайдер позиций: полноэкранные панели, гигантское слово за карточкой товара,
  переход-шторка с параллаксом, 3D-наклон за курсором. Позиции: шаурма, фри,
  картофель, наггетсы.
- `/menu/` — страница меню с корзиной: выбор позиций, подсчёт суммы, форма заказа
  и кнопка, которая собирает текст заказа для отправки в сообщения.

## Особенности

- Один HTML-файл на страницу: CSS, JS и фотографии вшиты внутрь — не нужны сервер,
  сборка и папки с картинками.
- Адаптив: телефон, планшет, ландшафт. Учитывается режим «уменьшить движение».
- Управление: вкладки, стрелки, клавиатура (← →), свайп, автопрокрутка с паузой.

## Локальный запуск

Открыть `index.html` в браузере. Или:

```bash
python -m http.server 8000
```

и зайти на http://localhost:8000

Фотографии взяты из открытого каталога сообщества и используются как демонстрационные.
